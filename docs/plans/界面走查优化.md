## 背景

维护者反馈「页面的 icon 都没得」「好多地方看着不合理」，要求按 ui-ux-pro-max 的规则走查。走查分 5 个方向（外壳与总览、聚焦与详情、来源、订阅推送与设置、图标与横向专项），在测试实例上按桌面 1440、平板 768–1279、手机 390 三档和深浅两色截图、实测尺寸与对比度，每组发现由另一个 agent 独立复核。共 98 条，复核剔除 2 条误报，保留 96 条（高 9、中 42、低 45），合并重复后约 75 个独立问题。

「从示例导入」「导入 YAML」两个对话框的问题（加载态、已导入判断、文件选择样式）不在本计划处理：《来源分享与仓库》计划会把这两个入口换成 JSON 导入与仓库浏览。

## 决策

| # | 问题 | 决定 |
|---|---|---|
| 1 | 实施范围 | 7 类全部实施，每类一个 PR |
| 2 | 图标块（IconTile）色调 | 实体图标块统一中性色，颜色只表示状态；品牌图标与来源头像自带颜色 |
| 3 | 来源图标 | 默认按名称首字生成头像、按 key 固定取色；来源定义增加可选 `icon`，只接受 data URI 图片（png、jpeg、webp、svg），大小有上限，不接受远程地址（避免加载第三方资源泄露访问记录）；编辑器提供上传 |
