## 背景

维护者反馈「页面的 icon 都没得」「好多地方看着不合理」，要求按 ui-ux-pro-max 的规则走查。走查分 5 个方向（外壳与总览、聚焦与详情、来源、订阅推送与设置、图标与横向专项），在测试实例上按桌面 1440、平板 768–1279、手机 390 三档和深浅两色截图、实测尺寸与对比度，每组发现由另一个 agent 独立复核。共 98 条，复核剔除 2 条误报，保留 96 条（高 9、中 42、低 45），合并重复后约 75 个独立问题。

「从示例导入」「导入 YAML」两个对话框的问题（加载态、已导入判断、文件选择样式）不在本计划处理：《来源分享与仓库》计划会把这两个入口换成 JSON 导入与仓库浏览。

## 决策

| # | 问题 | 决定 |
|---|---|---|
| 1 | 实施范围 | 7 类全部实施，每类一个 PR |
| 2 | 图标块（IconTile）色调 | 实体图标块统一中性色，颜色只表示状态；品牌图标与来源头像自带颜色 |
| 3 | 来源图标 | 默认按名称首字生成头像、按 key 固定取色；来源定义增加可选 `icon`，只接受 data URI 图片（png、jpeg、webp、svg），大小有上限，不接受远程地址（避免加载第三方资源泄露访问记录）；编辑器提供上传 |

## 收尾修正

各阶段复核提出的可选建议，在开 PR 前以 fixup 提交并入对应阶段：

- 可访问性：「接入清单」读屏名称带来源名；登录失败提示关联到输入框；聚焦页只保留一个 main 地标，侧栏纳入导航地标；画布的悬停与键盘聚焦分开记录
- 手机外壳：侧栏展开时用户菜单不重复显示深浅色；菜单项改用 select 事件；标签栏溢出时可滚动到首项
- 图标体系：SVG 图标拒绝脚本、事件属性、foreignObject、DOCTYPE / ENTITY 与外部引用（含字符引用与 CSS 转义写法，Windows 路径等正常内容不误伤）；停用来源的头像各处显示灰度；头像色板去掉与状态色、彼此相近的颜色；图标统一从对照表取；theme-color 随界面深浅色切换
- 响应式：流向图单列时单独显示统计；吸顶的待处理面板不再遮挡顶栏
- 详情一致性：未连通连线对比度 ≥3:1；停用的列表行改为「已停用」徽章；「管理推送规则」点击区域 ≥44px；两处叠加透明度导致的文字对比度不足
- 命令面板：手机条目 ≥44px；按「通知渠道」「推送规则」「API令牌」等词可找到对应页面；「取消」按钮右侧留白
- 来源编辑器：弹窗打开时只有带操作按钮的提示条可点击；删除后在原位置提供键盘可达的撤销；删除来源后返回列表；卡片标题长名称换行

整理后每个分支单独跑完整门禁，均通过。
