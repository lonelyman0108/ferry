## 背景与目标

Ferry 已经能用，但只能从源码构建；部署时环境变量必须把数据库和主密钥给全，少一项就启动失败；界面上也看不到自己跑的是哪个版本。

**目标**：拉一个镜像就能跑；向导能接住环境变量给出的部分配置；界面上能看到版本与运行环境，有新版本时提醒。

## 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 配置优先级反转 | 已有部署里环境变量和配置文件同时给了同一项时，生效的值会变 | 目前只有本机测试实例；部署文档写明新规则，系统信息页标出每一项的来源 |
| 去掉主密钥环境变量后进不去 | 回到向导、要求重新配置 | 部署文档写明：主密钥来自环境变量时不在配置文件里 |
| Docker Hub secret 未添加 | 发布时推 Docker Hub 失败 | 发布前确认；缺 secret 时只推 GHCR 并在发布记录里说明 |
