# 0001. Go 单二进制，内嵌前端

- 状态：生效（2026-10-23）
- 日期：2026-10-23

## 背景

Ferry 是自用工具，要同时跑在两种环境里：家里的 Docker 主机（linux/amd64、arm64），以及 Mac（用 launchd 运行）。部署和升级都由一个人做，组件越少越好。管理界面需要表单、表格、时间线这类常见控件，但没有复杂的交互。

## 决策

后端用 Go，前端用 Vue 3 + Vite + Element Plus。前端构建产物用 `embed` 打进二进制，最后只发一个可执行文件，同一个端口同时提供 API、管理界面、订阅和脚本。存储用 GORM，默认是 SQLite（纯 Go 驱动，不依赖 CGO），PostgreSQL 和 MySQL 在初始化向导里选。

## 后果

- 好处：交叉编译就能得到各平台的产物；Docker 镜像可以用 distroless；macOS 上不需要额外的运行时。
- 代价：构建前端要用 Node，CI 里先构建 `web/`，再编译 Go；开发时前后端分开跑，用 Vite 代理 API。
- 后续：`scripts/check.sh` 加上前端的 lint 和 build；三种数据库各跑一遍集成测试。

## 可推翻条件

某种数据库的迁移成本过高时，砍掉这个数据库，并写一篇新的 ADR。前端构建在 CI 里成为明显的负担时，再考虑预构建产物。
